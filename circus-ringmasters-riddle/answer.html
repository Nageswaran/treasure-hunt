Mission 01 · Easy

The Faded Poster

Answer: 1768
How to get there

Search "Philip Astley first modern circus year." On or about 9 January 1768, Philip Astley staged what's usually called the first modern circus in London, combining trick riding, acrobats, and clowns in one ring.

Why this is the only answer

Multiple independent history sources (Britannica, History.com, and circus-history specialist sites) agree on 1768 as the founding year, so it's the one clear number a search turns up.

Source / fact used

Verified via web search against Britannica's "Philip Astley" biography and History.com's "First modern circus is staged" article.

Mission 05 · Hard

The Missing Measurement

Answer: 4 (meters)
How to get there

The five readable sides (10, 4, 6, 14, 10 meters) add up to 44 meters. The full perimeter is 48 meters, so the missing side is 48 − 44 = 4 meters.

Why this is the only answer

All six sides of this L-shaped outline must sum to the stated total perimeter, so exactly one value completes the sum. The diagram is internally consistent: the two horizontal notch segments (10 m + 4 m) equal the full bottom width (14 m), and the two vertical notch segments (4 m + 6 m) equal the full left height (10 m).

Source / fact used

Self-drawn inline SVG diagram (no external image). Hand-recomputed: 10+4+6+14+10=44; 48−44=4.

Mission 07 · Big Aha (multi-stage)

The Locker Room

Stage 1 answer: 318
Stage 2 (final) answer: 96
How to get there

Stage 1: the Mission 2 notebook number is 63; the Mission 4 ticket total is 381. 381 − 63 = 318. Stage 2: digits of 318 are 3, 1, 8, which sum to 12. 12 × 8 = 96.

Why this is the only answer

Stage 2 explicitly operates on "your Stage 1 answer," so it only resolves once Stage 1 (318) is known — a genuine dependency. Both steps are plain arithmetic with one result each, and 96 fits the stated constraint that lockers only go up to 100.

Source / fact used

Self-contained calculation chain built from Mission 2's and Mission 4's answers. Hand-recomputed: 381−63=318; digits 3+1+8=12; 12×8=96.

Grand Finale

Behind Locker 96

Answer: trunk
How to get there

The Morse code groups decode as: – = T, ●–● = R, ●●– = U, –● = N, –●– = K, spelling TRUNK.

Why this is the only answer

Each International Morse code group maps to exactly one letter, so the decoded word is fixed and unambiguous.

Source / fact used

Standard International Morse code, verified letter-by-letter via web search (T = dash; R = dot-dash-dot; U = dot-dot-dash; N = dash-dot; K = dash-dot-dash) and hand-encoded from TRUNK.
