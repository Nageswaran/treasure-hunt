Mission 01 · Easy · Technology & Computers

The Scanner's Secret Code

Answer: SCAN
How to get there

Each 8-digit binary group is a letter's ASCII code. 01010011 = 83 = "S". 01000011 = 67 = "C". 01000001 = 65 = "A". 01001110 = 78 = "N". Together: S-C-A-N.

Why this is the only answer

ASCII binary-to-letter conversion is a fixed, one-to-one standard — each 8-digit group maps to exactly one letter, so there is only one possible decoded word.

Source / fact used

Standard ASCII character encoding (A=65 through Z=90); recomputed by hand from the exact binary digits given in the puzzle before publishing.

Mission 03 · Medium · Art & Culture / History (internet research)

The Illustrator's Legacy

Answer: 1938
How to get there

The Caldecott Medal, honoring English illustrator Randolph Caldecott (1846-1886), was established by the American Library Association in 1937 — but the first medal was actually awarded the following year, in 1938, to Dorothy P. Lathrop for "Animals of the Bible."

Why this is the only answer

The puzzle specifically asks for the year the medal was first AWARDED (not the year it was created/established), which is a single, well-documented historical fact with one correct year.

Source / fact used

Verified via web search: Wikipedia's "Caldecott Medal" entry and the Association for Library Service to Children (ala.org/alsc) both confirm the medal was established in 1937 and first awarded in 1938.

Mission 05 · Medium · Mathematics (Geometry, pen-and-paper)

The Bookplate's Missing Corner

Answer: 168
How to get there

The full rectangle would be 18 cm × 10 cm = 180 cm². The missing corner is a right triangle with legs 6 cm and 4 cm, so its area is (6 × 4) ÷ 2 = 12 cm². Subtracting: 180 - 12 = 168 cm².

Why this is the only answer

Every dimension needed (18, 10, 6, and 4) is labeled directly on the diagram, and the shape is fully determined by those four numbers, so there is exactly one possible area.

Source / fact used

Self-contained geometry puzzle; recomputed independently before publishing (18×10=180; 6×4÷2=12; 180-12=168) and the SVG polygon's coordinates were checked to match the labeled dimensions exactly (the diagonal cut spans exactly 6 cm horizontally and 4 cm vertically at the drawing's 1 cm = 12 px scale).

Answer: 140
How to get there

The Marginalia's Secret

Stage 1 answer: 3. According to the Roman historian Suetonius, Julius Caesar shifted each letter of his military correspondence forward by three places in the alphabet — the historical origin of the "Caesar cipher." Verified via web search (Suetonius's "Lives of the Caesars," cross-checked against Britannica's "Caesar cipher" entry).

Stage 2 answer: 7. Shifting VHYHQ backward by 3: V→S, H→E, Y→V, H→E, Q→N, spelling SEVEN — typed as the digit 7. This stage genuinely requires Stage 1's shift number (3); without it, the ciphertext cannot be decoded.

Stage 3 (final) answer: 34. 7 (the shelf number from Stage 2) × 12 volumes on that shelf = 84; 84 - 50 = 34, the page number the scanner choked on. This stage genuinely requires Stage 2's result (7).

Why this is the only answer

Each stage is a hard dependency on the one before it: Stage 2 cannot be decoded without Stage 1's verified shift number, and Stage 3's arithmetic cannot be done without Stage 2's decoded digit. Every stage was re-solved independently, in order, to confirm the chain produces exactly one final answer (page 34) — later explained in-story as an innocent torn page, not a theft.

Source / fact used

Historical fact (Caesar's shift of 3) verified via web search against Britannica and classical-history sources citing Suetonius. The cipher decoding and arithmetic were both recomputed by hand before publishing.
