Mission 01 · Easy

The Closet Keypad

Answer: 43
How to get there

Binary 101011, read left to right, uses place values 32-16-8-4-2-1. Add the columns with a 1: 32 + 8 + 2 + 1 = 43.

Why this is the only answer

Binary-to-decimal conversion is purely mechanical — there is exactly one decimal value for a given binary string, so 43 is the only correct conversion of 101011.

Source / fact used

Standard base-2 (binary) place-value conversion, taught as part of basic computer-science / number-systems curricula.

Mission 07 · Hard

The Hand-Drawn QR Grid

Answer: stage
How to get there

Each row is a 5-bit binary number (place values 16-8-4-2-1), converted to a letter with A=1...Z=26:

Row 1: 10011 = 16+2+1 = 19 = S
Row 2: 10100 = 16+4 = 20 = T
Row 3: 00001 = 1 = A
Row 4: 00111 = 4+2+1 = 7 = G
Row 5: 00101 = 4+1 = 5 = E

Reading the rows in order spells "STAGE" — a hint that the overflow cash box (found in Mission 8/the Finale) is stashed near the stage alcove from Mission 3.

Why this is the only answer

Binary-to-decimal-to-letter conversion is mechanical and one-to-one within A-Z, so each row yields exactly one letter and the five rows in order spell exactly one word.

Source / fact used

Real, verified fact used for story flavor: the QR code was invented in 1994 by engineer Masahiro Hara at Denso Wave (Japan) to track automobile parts in factories; "QR" stands for "Quick Response," and Denso Wave chose not to enforce its patent, making QR codes free to use worldwide. Sources: Wikipedia: QR code, Denso Wave: History of QR Code, Wikipedia: Masahiro Hara. The hand-drawn grid itself and its binary values are original to this puzzle, not a real QR code.

Mission 08 · Hard

Who Has the Spare Key?

Answer: Theo
How to get there

Test each person as the one mistaken statement:

If Sam is mistaken (Ruby, Theo truthful): Sam doesn't have the key. Ruby's "Sam does not have the key" is true — consistent. Theo's "I've got the spare key" is true — consistent. No contradictions: Theo has the key.

If Ruby is mistaken (Sam, Theo truthful): Sam has the key (his statement true) AND Theo has the key (his statement true) — but only one person can hold the single key. Contradiction — invalid.

If Theo is mistaken (Sam, Ruby truthful): Sam has the key (true). Ruby's "Sam does not have the key" would then have to be true too — but that directly contradicts Sam having it. Contradiction — invalid.

Only the first case holds together without contradiction, so Theo has the spare key (and Sam was the one joking/mistaken).

Why this is the only answer

Of the three possible "who is mistaken" assignments, two produce a direct logical contradiction and only one is fully self-consistent — a classic knights-and-knaves elimination with a single forced solution.

Source / fact used

Pure logic puzzle, verified by hand-checking all three cases above (see this session's design notes); no external source needed.

Grand Finale · Advanced Logical Reasoning (Combinatorics)

Cracking the Cash Box

Answer: teamwork
How to get there

Step 1 — find the code. Constraints: 3 digits summing to 11 (from Mission 9 Stage 2), first digit even, first digit specifically 4 (Maya's clue). That leaves 8 possible codes where digits 2 and 3 sum to 7: 407, 416, 425, 434, 443, 452, 461, 470.

Apply Jonas's clue (2nd digit bigger than 3rd): only 443, 452, 461, 470 survive (407, 416, 425, 434 all have a 2nd digit smaller than or equal to the 3rd).

Apply Priya's clue (3rd digit even, and not zero): 443 (3rd digit 3, odd) fails; 461 (3rd digit 1, odd) fails; 470 (3rd digit 0, even but zero) fails; 452 (3rd digit 2, even and not zero) passes. Exactly one code survives: 452.

Step 2 — decode the word. The digit-sum (11) is also the Caesar-shift amount. Shifting each letter of EPLXHZCV backward by 11 (wrapping A→Z as needed): E→T, P→E, L→A, X→M, H→W, Z→O, C→R, V→K, spelling TEAMWORK.

Why this is the only answer

The full 36-code space allowed by "digit-sum 11, first digit even" is narrowed by Maya's clue to the 8 codes starting with 4, then Jonas's clue removes 4 more, then Priya's clue removes all but one — verified by hand above, leaving exactly code 452. Caesar-shift decoding is a one-to-one, reversible operation, so shifting EPLXHZCV back by exactly 11 produces exactly one possible plaintext: TEAMWORK.

Source / fact used

Self-contained logic and arithmetic puzzle, fully re-solved by hand during mission design to confirm a single forced code and a single decoded word (no external source needed).

Reward revealed

The value word is teamwork — every mission's separate donation source, memory, and clue had to be combined by the club (and by the young detective) to add up to the true total, which is exactly what "teamwork" means in this case.
