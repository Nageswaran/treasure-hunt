How to get there

Multiple independent, reputable sources (chess history sites, Wikipedia, museum-style write-ups) agree India is the documented birthplace of chaturanga — this is presented as the well-established consensus, not a contested claim, so no other country is a defensible answer for this question.

The Clock That Never Lies

Answer: 78.5
How to get there

Full circle area = π × r² = 3.14 × 10² = 3.14 × 100 = 314 cm². The shaded wedge is 90° out of 360°, i.e. exactly 1/4 of the circle. Sector area = 314 ÷ 4 = 78.5 cm². Recomputed independently to confirm: (90/360) × 3.14 × 100 = 0.25 × 314 = 78.5.

Both the radius (10 cm) and the angle (90°) are labeled directly on the diagram, and π is fixed at 3.14 by the puzzle text, so the calculation has exactly one numeric result. The diagram's drawn wedge (from the 12 o'clock line to the 3 o'clock line) is a genuine quarter-circle, consistent with the labeled 90°.

Mission 04 · Medium · Cryptography

The Zigzag Farewell

Answer: endgame
How to get there

The plaintext "ENDGAME" (7 letters) was encoded by hand on 3 rails. Zigzag row assignment by letter position (1-7): position 1→row1, 2→row2, 3→row3, 4→row2, 5→row1, 6→row2, 7→row3.
Row 1 (positions 1,5): E, A → "EA"
Row 2 (positions 2,4,6): N, G, M → "NGM"
Row 3 (positions 3,7): D, E → "DE"
Reading rows in order gives the ciphertext: EA + NGM + DE = EANGMDE.
Decoding reverses this: split EANGMDE into chunks of 2, 3, 2 (matching each row's letter count), place them back onto the zigzag skeleton, then read down the zigzag path (position 1 through 7) to recover E-N-D-G-A-M-E = ENDGAME.

Why this is the only answer

The round trip was independently verified by hand (encode ENDGAME → EANGMDE, then decode EANGMDE → ENDGAME) before publishing, confirming no transcription errors. The 3-rail zigzag skeleton shown to the child fully determines the unique letter placement, so there is exactly one valid decoding.

Source / fact used

Rail fence cipher mechanic (general knowledge, not previously used elsewhere in this repo per the brief); encoding performed and checked manually for this mission.

Mission 05 · Medium · Logical Reasoning (Foundational — classification / Venn diagram)

Sorting the Army

Answer: bishop and queen
How to get there

Piece-by-piece, using each piece's normal move (no pawn double-step, no capture rules):

  • Rook — moves any distance along a rank/file only (straight lines). Diagonal: no. Multi-square: yes. → Circle B only.
  • Bishop — moves any distance along a diagonal only. Diagonal: yes. Multi-square: yes. → Overlap (A and B).
  • Queen — moves any distance along a rank, file, or diagonal. Diagonal: yes. Multi-square: yes. → Overlap (A and B).
  • King — moves exactly one square in any direction, including diagonally. Diagonal: yes. Multi-square: no (always exactly 1). → Circle A only.
  • Knight — moves in a fixed L-shape jump, never diagonally, never slides. → Outside both circles.
  • Pawn — normal move is one square straight ahead (diagonal is only for capturing, explicitly excluded by the puzzle's rules). → Outside both circles.

Only Bishop and Queen satisfy both "moves diagonally" and "can slide more than one square in a turn," so they are the two pieces in the overlap.

Why this is the only answer

Every one of the six pieces was checked individually against both circle definitions; only two pieces satisfy both conditions simultaneously, and the puzzle explicitly asks the child to list all pieces in the overlap (not assume just one), so "bishop and queen" (alphabetical order, as instructed) is the single correct, complete answer.

Source / fact used

Standard, well-established chess piece movement rules (own confirmed chess knowledge, consistent with any standard chess rules reference, e.g. Chess.com — How to Play Chess).

Mission 07 · Hard · Dutch Language (de/het)

The Flashcard Tin

Answer: paard
How to get there

Full classification of the six flashcards, each verified individually via web search (not guessed):

  • de koning (king) — common gender.
  • de koningin (queen) — common gender.
  • de toren (rook/tower) — common gender.
  • het paard (knight/horse) — neuter. Dutch farm-and-stable animal names (paard, schaap, kalf, lam, varken) are a well-known exception group that takes "het" even though most nouns take "de."
  • de loper (bishop) — common gender; agent nouns ending in "-er" are almost always "de" words.
  • de pion (pawn) — common gender.

Five of the six words take "de." Only "paard" takes "het," making it the one that breaks the pattern.

Why this is the only answer

Each word's article was checked individually against a Dutch dictionary source, not assumed. Exactly one word (paard) is neuter; the other five are common gender, so there is exactly one correct "odd one out."

Source / fact used

Verified via web search against Dutch dictionary/grammar sources: Yktoo — Het-noun cheat sheet (confirms "het paard" and the farm-animal exception group), Woorden.org — pion (confirms "de pion," masculine), Woorden.org — klok (used to cross-check the "-er"/common-gender pattern), and Dutch Wikipedia pages for Koning, Koningin/Dame, and Toren in chess (all consistently referred to as "de").
