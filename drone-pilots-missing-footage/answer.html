Mission 02 · Easy · Dutch Language

Sorting the Ranger Station's Word Cards

Answer: 3
How to get there

de drone, de camera, de vleugel take "de" (3 words). het geheugenkaartje, het dier, het signaal take "het" (3 words). So exactly 3 of the 6 cards use "het."

Why this is the only answer

Dutch grammatical gender is fixed per word, and "geheugenkaartje" is a diminutive (ends in "-je"), which is always "het" regardless of the base word's own gender ("kaart" itself is a de-word, but the diminutive form overrides that) — this is a fixed grammar rule, not a judgment call.

Source / fact used

Verified via web search against Van Dale ("de drone"), Woorden.org and welklidwoord.nl/welklidwoord.be ("het dier," "het signaal"), and the general Dutch diminutive rule (all "-je" nouns are "het," confirmed via multiple Dutch-grammar reference sites) for "het geheugenkaartje."

The Battery's Last Words

Answer: LOW
How to get there

Why this is the only answer

Standard ASCII binary-to-letter mapping is a fixed, one-to-one lookup table (also given directly in the puzzle for the relevant letters), so each 8-digit block decodes to exactly one letter, and the three blocks in order spell exactly one word.

Big "Aha!" Moment · Logical Reasoning (Advanced — combinatorics/counting)

Cracking the Autopilot's Rulebook

Answer: 14
How to get there

Systematic count by first symbol (only N or E allowed):

Codes starting with N: second symbol can be S, E, or W (not N).
• N-S-?: third symbol can't be S (repeat) or W (last-symbol rule) → only N or E → 2 codes (NSN, NSE).
• N-E-?: third symbol can't be E or W → only N or S → 2 codes (NEN, NES).
• N-W-?: third symbol can't be W (repeat, and also banned as last symbol anyway) → N, S, or E all allowed → 3 codes (NWN, NWS, NWE).
Subtotal for N: 2 + 2 + 3 = 7.

Codes starting with E: by the same logic (E is symmetric to N under these rules):
• E-N-?: not N or W → S or E → 2 codes (ENS, ENE).
• E-S-?: not S or W → N or E → 2 codes (ESN, ESE).
• E-W-?: not W (only ban) → N, S, or E → 3 codes (EWN, EWS, EWE).
Subtotal for E: 2 + 2 + 3 = 7.

Total valid codes: 7 + 7 = 14.

Why this is the only answer

All three rules are fixed and unambiguous (allowed first symbols, no immediate repeats, banned last symbol), so a full systematic enumeration — covering every branch exactly once, as shown above — is guaranteed to find every valid code and no invalid ones. Re-enumerating independently (grouping by first symbol) reproduces 14 both times.

Source / fact used

Self-contained combinatorics puzzle; solved by exhaustive, systematic listing (not estimation), double-checked by regrouping the count a second way (by middle symbol) and confirming the same total of 14.
