Mission 06 · Hard

The Final Stretch

Answer: 254
How to get there

Elevation drop: 2,720 m (Sun Gate) − 2,430 m (Machu Picchu) = 290 m. Divide by 10: 290 ÷ 10 = 29. Southwest bearing: halfway between south (180°) and west (270°) = 225°. Waypoint code: 29 + 225 = 254.

Why this is the only answer

Both elevations and the compass math are fixed values stated in the puzzle, so the calculation produces exactly one number.

Source / fact used

Verified via web search: multiple Inca Trail trekking guides (e.g. Salkantay Trekking, Vidal Expeditions) confirm the Sun Gate (Inti Punku) sits at roughly 2,720-2,730 m and Machu Picchu itself at about 2,430 m, with the trail's final stretch descending from the Sun Gate down into the citadel. The southwest compass bearing (225°) is standard compass geometry, not a claimed real-world fact.

Mission 07 · Hard

The Knotted Cord

Answer: 374
How to get there

Hundreds place: 3 single knots = 300. Tens place: 7 single knots = 70. Ones place: a long knot with 4 turns = 4. Total: 300 + 70 + 4 = 374.

Why this is the only answer

Each place value is fixed by its position on the cord (closest to the main cord = biggest place value), and each knot type/count maps to exactly one digit under the real quipu system, so the reading is unambiguous.

Source / fact used

Verified via web search against academic math-history resources (Lumen Learning "Inca and Quipu Numeration Systems," Math LibreTexts "The Number and Counting System of the Inca Civilization"): quipu used a base-10 positional system where clusters of single knots represented digits at the tens/hundreds/etc. positions, while the ones position used a long knot (number of turns = digit, for 2-9) or a figure-eight knot (= 1). This is the real historical system, not an invented code.
