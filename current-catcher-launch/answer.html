Mission 02 · Easy

Two Ways Plastic Hurts

Answer: fishing line
How to get there

An abandoned fishing net mainly causes entanglement (animals get physically caught in it). A plastic bottle cap mainly causes ingestion (birds and fish swallow it, mistaking it for food). Fishing line does both: NOAA Fisheries and marine-debris researchers document it as a hazard that both entangles wildlife (wrapping around fins, flippers, and necks) and gets swallowed (hooks, line, and other gear ingested internally).

Why this is the only answer

Nets and bottle caps are each cleanly one category in the sources used; only fishing line is documented as doing both, which is exactly what "belongs in the overlap" means.

Source / fact used

NOAA Fisheries, "Entanglement of Marine Life: Risks and Response" (fisheries.noaa.gov) and NOAA's Marine Debris Program page on wildlife entanglement and ghost fishing both describe fishing line as causing external entanglement and internal ingestion. Bottle-cap ingestion by seabird chicks is documented by Oceana and the Smithsonian Ocean portal (Laysan albatross chicks at Midway Atoll).

Mission 03 · Medium

Which Claim Is Right?

Answer: claim b
How to get there

Real cleanup organizations consistently say cleanup and prevention are both necessary — cleanup alone does not solve the problem, because new plastic keeps entering the water. Claim A's "solves it completely, forever, all by itself" overstates what any single machine can do.

Why this is the only answer

Claim A is contradicted by cleanup organizations' own public statements about the limits of cleanup technology; Claim B directly matches them.

Source / fact used

Ocean Blue Project: "Ocean cleanup alone is not enough. To create lasting change, we must also reduce the amount of plastic entering the environment." The Ocean Cleanup's own FAQ similarly states that stopping plastic from entering the ocean and cleaning up what's already there are both necessary.

Mission 05 · Medium

The Morning Blink Code

Answer: READY
How to get there

10010 = 18th letter = R. 00101 = 5th letter = E. 00001 = 1st letter = A. 00100 = 4th letter = D. 11001 = 25th letter = Y. Together: R-E-A-D-Y.

Why this is the only answer

Each 5-digit binary group maps to exactly one letter via the supplied table; there is only one way to read the five groups in order.

Source / fact used

Mission 06 · Hard

The Harbor Permit

Answer: 114
How to get there

Triangle area = ½ × base × height = ½ × 12 × 9 = 54 m². Rectangle area = length × width = 12 × 5 = 60 m². Total footprint = 54 + 60 = 114 m².

Why this is the only answer

All dimensions needed are labeled directly on the diagram, and the triangle's base (12 m) and the rectangle's top edge (12 m) are the same shared seam, so the two shapes are drawn to agree with each other and with the math.

Source / fact used

Standard area formulas (triangle = ½ base × height; rectangle = length × width), reminded in Hint 2 for any child unfamiliar with the triangle formula.

Mission 07 · Hard

Which Sensor Do We Trust?

Answer: South
How to get there

The crew already knows for certain (from the dock's hand-checked instrument) that the current is NOT exactly 4 knots. Sensor South claims it IS exactly 4 knots — a claim that's objectively false regardless of anything else. Since a working sensor can never say something false, Sensor South must be the broken one. That also makes Sensor North the working sensor, and North's statement ("Sensor South is broken") checks out as true — no contradictions either way.

Why this is the only answer

South's statement is checked against an independent, already-known fact (not against North's statement), which breaks the "he-said, she-said" symmetry a plain knights-and-knaves pair would have and forces exactly one consistent solution.

Source / fact used

Self-contained logic puzzle (truth-teller/liar mechanic); solved purely from the clues given, no outside lookup.

Mission 08 · Hard (multi-stage)

Chart the Mooring Spot

Stage 1 answer: 135
How to get there

On a compass, North is 0°, East is 90°, South is 180°, West is 270°. Southeast sits exactly halfway between East and South: (90 + 180) ÷ 2 = 135°.

Source / fact used

Standard compass-bearing convention, confirmed via sources such as Mathwords' "Bearing in Math" page and SummitPost's compass-basics guide: a bearing of 135° is due Southeast.

Stage 2 (final) answer: F5
How to get there

135° (Southeast) means each step moves one column right (east) and one row down (south). Starting at C2 and taking 3 such diagonal steps: row C (3rd row) + 3 rows → row F (6th row); column 2 + 3 columns → column 5. Landing square: F5.

Why this is the only answer

Stage 2 genuinely depends on Stage 1: without knowing the bearing is 135° (Southeast, not Northeast/Southwest/Northwest), the child wouldn't know which diagonal direction to move. The starting square (C2) and step count (3) are fixed, so the landing square is uniquely determined.

Source / fact used

Grid-reading/map-direction reasoning built into the puzzle's own self-drawn chart.
