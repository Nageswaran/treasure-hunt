Mission 01 · Easy

The Empty Place on the Map

Answer: Norway
How to get there

Searching "first explorers to reach the South Pole" turns up Roald Amundsen's Norwegian expedition, which reached the South Pole on December 14, 1911, and planted the Norwegian flag, naming the surrounding plateau after King Haakon VII.

Why this is the only answer

Every reputable source (Wikipedia, History.com, Scientific American, UNESCO) names Amundsen's Norwegian team as first, with a Norwegian flag planted at the pole.

Source / fact used

Verified via web search: Wikipedia — Amundsen's South Pole expedition; History.com, "Amundsen reaches South Pole".

Mission 03 · Medium

The Dutch Curator's Sticky Note

Answer: kompas
How to get there

"de slee," "de vlag," and "de tent" all take "de." "Kompas" is a neuter (het) noun in Dutch, so it takes "het kompas" instead.

Why this is the only answer

Only one of the four words is grammatically neuter; the other three are confirmed common-gender (de) nouns.

Source / fact used

Verified via web search: Woorden.org entry for "kompas" (confirms "het kompas," neuter gender); Wikipedia, "Gender in Dutch grammar."

The Hut With a Missing Wall

Answer: 9 (meters)
How to get there

Add the five known walls: 11 + 4 + 5 + 5 + 16 = 41 meters. The total distance around the hut is 50 meters, so the missing wall is 50 - 41 = 9 meters.

Why this is the only answer

An L-shaped figure has exactly six sides; five are labeled and their sum plus the sixth must equal the stated total perimeter of 50 m. This also matches the outer bounding rectangle's height (9 m), confirming the diagram is internally consistent.

Self-drawn, self-verified diagram/geometry puzzle. Coordinates re-checked: bounding box 16 m × 9 m with a 5 m × 4 m notch removed; perimeter of an L-shape equals the bounding rectangle's perimeter, 2 × (16 + 9) = 50 m.

Mission 05 · Medium

The Bird That Loves Winter

Answer: Emperor penguin
How to get there

Searching "only penguin that breeds in Antarctic winter" identifies the emperor penguin — males incubate a single egg on their feet through the Antarctic winter while fasting for about nine weeks.

Why this is the only answer

Multiple sources agree the emperor penguin is the only penguin species — and the only Antarctic bird species — that breeds during the winter.

Source / fact used

Mission 06 · Hard

The Signal Lamp

Answer: FRAM
How to get there

Matching each Morse group to the key: ··–· = F, ·–· = R, ·– = A, –– = M, spelling FRAM — the real name of Amundsen's polar ship.

Why this is the only answer

International Morse code assigns exactly one letter to each dot/dash pattern, so the decode is unambiguous and forced.

Source / fact used

Verified via web search: International Morse Code reference (morsecode.world); ship name confirmed via Wikipedia, "Amundsen's South Pole expedition" (Fram, meaning "forward" in Norwegian).
