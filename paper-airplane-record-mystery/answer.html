Mission 01 · Easy · Science & Nature

Four Forces, Mixed Up

Answer: drag
How to get there

Force 4 describes air pushing back against every surface of the plane, opposite to its direction of travel — that is the definition of drag. (Force 1 = gravity, Force 2 = thrust, Force 3 = lift.)

Why this is the only answer

Each of the four descriptions matches exactly one of the four named forces of flight (lift, gravity, thrust, drag) with no overlap, so only "drag" fits Force 4.

Source / fact used

The four forces of flight (lift, gravity/weight, thrust, drag) are standard, verified aerodynamics — confirmed via web search of kid-level flight-science explainers (e.g. Science Buddies, How Wee Learn "Four Principles of Flight").

Mission 03 · Medium · Mathematics (geometry/measurement)

The Wingspan Blueprint

Answer: 18 (centimeters)
How to get there

The wing panel is a right triangle: one leg (along the spine) = 12 cm, hypotenuse (nose-to-wingtip fold line) = 15 cm. Using the Pythagorean theorem: 12² + b² = 15² → 144 + b² = 225 → b² = 81 → b = 9 cm. That 9 cm is the distance from the spine to one wingtip. Since the plane is symmetric, the other wing mirrors it exactly, so the total wingspan (tip to tip) = 9 + 9 = 18 cm.

Why this is the only answer

12-9-15 is a scaled 3-4-5 Pythagorean triple (×3), so there is exactly one positive value for the missing leg. Doubling it for the mirrored wing gives one forced total wingspan.

Source / fact used

Pure geometry (Pythagorean theorem), self-contained in the puzzle. Diagram coordinates were built to the exact stated measurements and checked for consistency: the drawn triangle points (20,105)-(116,105)-(116,33) give leg lengths of 96px and 72px and a hypotenuse of 120px, which at the diagram's 8px-per-cm scale correspond exactly to 12 cm, 9 cm, and 15 cm.

Mission 06 · Hard · Logical Reasoning (Intermediate — truth-tellers and liars)

Three Statements, One Truth

Answer: Priya
How to get there

Test each person as the lone truth-teller:

If Priya is the truth-teller: Priya's statement is true (she didn't swap). Sam's statement is false, so Noor did NOT swap. Noor's statement ("Sam is lying") is false, meaning Sam is actually telling the truth — but that's a second truth-teller, which breaks the "exactly one" rule. Contradiction — Priya is not the truth-teller.

If Sam is the truth-teller: Sam's statement is true, so Noor swapped the pages. Priya's statement is false, so Priya swapped the pages too. Two culprits can't both be right when only one person swapped the pages. Contradiction — Sam is not the truth-teller.

If Noor is the truth-teller: Noor's statement ("Sam is lying") is true, so Sam is lying, which is consistent (only Noor is truthful). Sam lying means "Noor swapped the pages" is false, so Noor did not swap them. Priya lying means "I did not swap the pages" is false, so Priya DID swap them. No contradictions — this is consistent all the way through.

So Noor is the truth-teller, and Priya swapped the pages.

Why this is the only answer

Testing all three possible truth-tellers by hand shows only the "Noor is truthful" branch avoids contradiction, so the culprit (Priya) is uniquely forced.

Source / fact used

Self-contained knights-and-knaves style logic puzzle, hand-solved branch by branch to confirm a single forced solution.
