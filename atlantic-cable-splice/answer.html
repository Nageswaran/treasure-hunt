Mission 01 · Easy · Technology & Geography

The Town Without Wi-Fi

Answer: Katwijk
How to get there

Search "TAT-14 cable Netherlands landing station." TAT-14 was a real transatlantic fiber-optic cable system (in service 2001-2020) connecting the US to the UK, France, the Netherlands, Germany, and Denmark. Its Dutch landing station was at Katwijk (Katwijk aan Zee), South Holland — KPN's cable station there was designated Segment T5 of the network.

Why this is the only answer

Katwijk is the specific, named Dutch landing point for TAT-14 across multiple independent sources (Submarine Networks, Lightwave). Accept "Katwijk" or "Katwijk aan Zee" — the mission asks for just the town name.

Source / fact used

Verified via web search: submarinenetworks.com ("TAT-14 - Submarine Networks"), lightwaveonline.com ("TAT-14 undersea cable system completes final phase"), and corroborating Wikipedia/database.earth listings for Katwijk aan Zee. Also verified: fiber-optic cables carry binary data as laser light pulses (light = 1, no light = 0), and a hair-thin glass strand can carry terabits of data per second (rochester.edu, broadbandsearch.net).

Mission 02 · Easy · History

The Cable That Almost Worked

Answer: 1866
How to get there

Search "first successful permanent transatlantic telegraph cable year." The 1858 cable (laid by Cyrus Field's team) worked for about three weeks before failing when excessive voltage was applied. After further failed attempts in 1865, the ship Great Eastern finally laid a lasting cable in 1866 — leaving Valentia, Ireland on 13 July 1866 and completing the final splice at Heart's Content, Newfoundland on 27 July 1866.

Why this is the only answer

1858 is a tempting wrong answer since it's the year most sources mention first, but the mission explicitly asks for the year the cable "finally worked for good and stayed in service" — that is 1866, confirmed across every source consulted.

Source / fact used

Verified via web search, corroborated across: IET archives ("The Transatlantic Telegraph Cables 1865-1866"), IEEE ETHW ("Milestones: Landing of the Transatlantic Cable, 1866"), ASCE ("Perseverance pays off: The Transatlantic Telegraph Cable"), and PBS American Experience ("Attempts to Lay the Transatlantic Cable" — "twelve years and five attempts").

Mission 03 · Medium · Cryptography

The Diagnostic Blink

Answer: FAULT
How to get there

Decode each 5-bit binary group into a number 1-26 using place values 16-8-4-2-1, then map to a letter (A=1 ... Z=26):

00110 = 4+2 = 6 = F
00001 = 1 = A
10101 = 16+4+1 = 21 = U
01100 = 8+4 = 12 = L
10100 = 16+4 = 20 = T

F-A-U-L-T = FAULT.

Why this is the only answer

Each binary group maps to exactly one number 1-26 and exactly one letter under the stated A=1...Z=26 key, so there is only one possible decoded word.

Source / fact used

Binary encoding mechanic verified via web search on how fiber-optic cables actually encode data as light pulses representing 1s and 0s (a laser "on" pulse = 1, "off" = 0) — the same underlying concept used for this puzzle's simplified 5-bit letter cipher.

Big "Aha!" Moment · Logical Reasoning (Advanced — Working Backward)

Three Nights, One Missing Number

Answer: 6
How to get there

Let x = the first buoy's distance from shore. The second buoy's distance = 2x. The third buoy's distance = x + 2x = 3x. We're told the third buoy is 18 km from shore, so 3x = 18, meaning x = 6.

Why this is the only answer

This is a single linear equation (3x = 18) with exactly one solution. Working backward from the one known value (18 km) is the only way to recover x, since the individual distances of buoys 1 and 2 are never stated directly.

Source / fact used

Pure backward-reasoning/algebra puzzle, solvable entirely from the relationships given in Chief Engineer Okafor's note — no outside lookup needed. Solved independently to confirm the single forced value.
