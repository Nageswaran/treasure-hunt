Mission 03 · Medium · Mathematics (pen-and-paper)

How Far Does One Click Travel?

Answer: 40
How to get there

Wave 1: the first classmate forwards to 3 friends = 3 people. Wave 2: each of those 3 forwards to 3 more = 3 × 3 = 9 people. Wave 3: each of those 9 forwards to 3 more = 9 × 3 = 27 people. Total who have seen it = the first classmate (1) + wave 1 (3) + wave 2 (9) + wave 3 (27) = 1 + 3 + 9 + 27 = 40.

Why this is the only answer

The problem explicitly says to count the very first forwarder plus every subsequent wave, and gives an exact branching factor (3) and exact number of waves (3), leaving no room for a different total. Verified by direct computation (3¹+3²+3³ = 3+9+27 = 39, plus the original forwarder = 40).

Source / fact used

Self-contained arithmetic word problem; recomputed independently with a script to confirm 40 is exact.

Mission 05 · Medium · Dutch Language (de/het)

De of Het? Coach Fenna Never Gets This Wrong

Answer: wachtwoord
How to get there

de robot, de club, de link — all three take "de." Only "wachtwoord" (password) takes "het": het wachtwoord. "Wachtwoord" is a compound neuter noun in Dutch (built from "wacht" + "woord," and "woord" itself is "het woord"), so it is standardly a het-word.

Why this is the only answer

Verified each of the four words individually — robot, club, and link are all confirmed de-words, and wachtwoord is the sole confirmed het-word, so exactly one odd-one-out exists.

Source / fact used

Verified via Dutch lidwoord reference sites: welklidwoord.nl/wachtwoord and webwoordenboek.nl (het wachtwoord); welklidwoord.nl/link and webwoordenboek.nl (de link); webwoordenboek.nl/robot and Van Dale (de robot); ensie.nl/de-of-het/club (de club).

Mission 08 · Hard · Cryptography (Caesar cipher)

Crack the Fake "Verification Code"

Answer: totally real trust me
How to get there

The crib "FRGH decodes to CODE" reveals the shift: F(5th letter, 0-indexed 5)→C(2), a shift of +3 in the encoding direction (each plaintext letter was moved 3 places forward to make the ciphertext). To decode, shift every ciphertext letter backward by 3: WRWDOOB→TOTALLY, UHDO→REAL, WUXVW→TRUST, PH→ME. Full decoded message: "TOTALLY REAL TRUST ME."

Why this is the only answer

The shift is uniquely determined by the given crib (only a shift of 3 turns CODE into FRGH), so applying that single shift to the rest of the ciphertext produces exactly one decoded result. Verified independently with a script: shifting "CODE" by +3 produces "FRGH," and shifting "WRWDOOB UHDO WUXVW PH" by -3 produces "TOTALLY REAL TRUST ME."

Source / fact used

Self-contained Caesar cipher, computationally verified. The in-story lesson (a real verification code is only random numbers, never a sentence) reinforces that unsolicited "verification codes" sent to prove identity are themselves a scam tactic.

Mission 09 · Big "Aha!" · Logical Reasoning (Advanced — working backward) + Internet Research (multi-stage)

How Did They Really Get In?

Stage 1 answer: data breach
How to get there (Stage 1)

Working backward from the effect (the scammer had Robin's exact password on the first try, no failed attempts, and Robin never clicked anything suspicious): the password wasn't guessed (no failed attempts) and wasn't phished directly from Robin (he clicked nothing). The only remaining explanation, combined with Mission 04's clue that Robin reused his password on an old game website, is that the old site's stored passwords were stolen and leaked — a data breach — and the scammer picked up Robin's reused password from that leak.

Why Stage 1 is the only answer

The clues explicitly rule out guessing (no failed attempts) and direct phishing (no click), leaving only a third-party leak as the explanation consistent with "correct on the first try" — and Mission 04 already established the reused-password habit that makes a breach the connecting mechanism.

Source / fact used

"Data breach" and "password reuse" as an attack vector is standard, widely documented cybersecurity concept (e.g., CISA and NIST guidance on why unique passwords matter, cisa.gov/MFA).

Stage 2 (final) answer: 2FA
How to get there (Stage 2)

The child researches the real security feature that stops a stolen/leaked password from being enough to log in: two-factor authentication (2FA), which requires a second proof (like a one-time code) in addition to the password. This directly follows from Stage 1's conclusion — because the password leaked through no fault of Robin's, only a second layer of protection (2FA) would have kept the account safe regardless.

Why Stage 2 is the only answer

The question asks specifically for the common short abbreviation (not the full name), and "2FA" is the standard, universally used abbreviation for two-factor authentication — no other common security term fits both the description (second step after a password) and the requested 3-character abbreviation format.

Source / fact used

CISA guidance on multi-factor authentication (cisa.gov/MFA and cisa.gov/topics/cybersecurity-best-practices/multifactor-authentication): "even if a malicious cyber actor compromises one factor like a password, they will be unable to meet the second authentication requirement," which stops stolen or reused passwords from being enough on their own.

Grand Finale · Financial Literacy / Critical Thinking / Internet Research + Cryptography (multi-stage)

Case Closed: The Real Rule About Real Prizes

Stage 1 answer: No
How to get there (Stage 1)

The child searches for real consumer-protection guidance on prize/sweepstakes scams (e.g., the U.S. Federal Trade Commission's consumer advice) and finds the core rule: you cannot legitimately win a prize for a contest you never entered, and real prizes never require payment or a suspicious click to claim. Since nobody in the CircuitFoxes chat ever entered any giveaway, the "prize" fails this basic legitimacy test — the answer is NO.

Why Stage 1 is the only answer

This is a factual question with one verified real-world answer (legitimate contests require entry), not a matter of opinion, so only "No" is consistent with real information.

Source / fact used

Federal Trade Commission consumer advice: "You cannot win a contest you didn't enter," and legitimate sweepstakes never require payment to claim a prize (consumer.ftc.gov/articles/fake-prize-sweepstakes-and-lottery-scams and consumer.ftc.gov/consumer-alerts/2025/06/dont-pay-prize-scam). For reporting real scams, a reputable kid-appropriate resource is NetSmartz (missingkids.org/netsmartz), run by the National Center for Missing & Exploited Children.

Stage 2 (final) answer: WISDOM
How to get there (Stage 2)

The recap lists exactly 5 red flags: (1) the copy-cat handle (@Coach_Fenna_HQ), (2) the countdown urgency ("before midnight"), (3) the lookalike web address, (4) the fake "verification code" that was really words, (5) the never-entered prize. That count, 5, is the shift. Decoding "BNXITR" by shifting each letter backward by 5: B→W, N→I, X→S, I→D, T→O, R→M, spelling WISDOM.

Why Stage 2 is the only answer

The red-flag list is explicitly enumerated in the puzzle text with exactly 5 items, so the shift number is forced; applying that single forced shift to the given ciphertext produces exactly one decoded word. Verified independently with a script: shifting "WISDOM" forward by 5 produces "BNXITR," confirming the reverse shift of 5 correctly recovers "WISDOM."

Source / fact used

Self-contained recap + Caesar cipher, computationally verified.
