Mission 01 · Easy

The Explorer's Year

Answer: 1642
How to get there

Search "Abel Tasman Tasmania New Zealand year discovered." Tasman reached and named Van Diemen's Land (Tasmania) on 24 November 1642, and his expedition sighted the New Zealand coast on 13 December 1642 — both in the same year.

Why this is the only answer

Independent history sources (national encyclopedias and museums of both countries) agree on 1642 as the year for both events, so the year is unambiguous even though the exact days differ between the two landings.

Source / fact used

Verified via web search against NZ History ("Abel Tasman"), Te Ara Encyclopedia of New Zealand, and Britannica's Abel Tasman biography.

Mission 02 · Easy

The Torn Compass Rose

Answer: northeast
How to get there

On a compass, the direction directly opposite Southwest (halfway around the circle) is Northeast.

Why this is the only answer

Every compass direction has exactly one opposite, 180° away — Southwest's opposite is always Northeast, regardless of orientation, since North is confirmed at the top of this chart.

Source / fact used

Self-contained spatial-reasoning puzzle — standard compass geometry, no outside lookup needed.

Mission 04 · Medium

The Conservator's Note

Answer: beacon
How to get there

Shift each letter of EHDFRQ back by 3: E→B, H→E, D→A, F→C, R→O, Q→N, spelling BEACON.

Why this is the only answer

A Caesar shift of 3 has exactly one correct reverse-shift, so each letter maps to exactly one decoded letter — there's only one possible decoded word.

Source / fact used

Standard Caesar-cipher shift of 3, hand-encoded from BEACON and hand-verified in reverse: B+3=E, E+3=H, A+3=D, C+3=F, O+3=R, N+3=Q, confirming EHDFRQ decodes back to BEACON.

Mission 05 · Hard

The Shape of the Island

Answer: 116 (square kilometers)
How to get there

Rectangle area = 12 km × 8 km = 96 km². Triangle area = ½ × 8 km × 5 km = 20 km² (using the shared 8 km edge as the triangle's base and the 5 km point as its height). Total = 96 + 20 = 116 km².

Why this is the only answer

The triangle's base is explicitly the same edge as the rectangle's height (shown as the dashed line in the diagram), so there's no ambiguity about which measurement to use for the base — the three given numbers (12, 8, 5) determine one total area.

Source / fact used

Self-drawn inline SVG diagram (no external image). Hand-recomputed: 12×8=96; ½×8×5=20; 96+20=116.

Grand Finale

The Chart's Last Corner

Answer: courage
How to get there

Using the Atbash cipher (A↔Z, B↔Y, C↔X, and so on): X↔C, L↔O, F↔U, I↔R, Z↔A, T↔G, V↔E, spelling COURAGE.

Why this is the only answer

Atbash is a fixed, symmetric letter-swap (each letter has exactly one partner), so the decoded word is unique. Hand-verified: C(3)↔X(24), O(15)↔L(12), U(21)↔F(6), R(18)↔I(9), A(1)↔Z(26), G(7)↔T(20), E(5)↔V(22).

Source / fact used

Standard Atbash substitution cipher (mirror-reverse alphabet), hand-encoded from COURAGE and hand-verified in reverse.
