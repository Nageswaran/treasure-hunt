Mission 04 · Medium

The Mathematician's Machine

Answer: Bombe
How to get there

Search "Alan Turing machine that cracked Enigma." Alan Turing, working at Bletchley Park, designed the Bombe — a machine that sped up finding the daily Enigma settings.

Why this is the only answer

The Bombe is the specific, named machine Turing is credited with designing for this purpose; search results consistently name it, distinguishing it from the German Enigma machine itself (which is not something Turing designed).

Source / fact used

Verified via web search summarizing the Imperial War Museums and the National WWII Museum: Alan Turing designed the Bombe at Bletchley Park to help break Naval Enigma.

Mission 07 · Big Aha

The Rotor Puzzle

Answer: 60
How to get there

Search confirms the German Army/Luftwaffe Enigma operators could choose rotors from a set of 5. With 3 slots to fill and no repeats, the first slot has 5 choices, the second has 4 remaining choices, and the third has 3 remaining choices: 5 × 4 × 3 = 60.

Why this is the only answer

This is a standard permutation calculation (order matters, no repeats) with exactly one correct product; re-verified by hand as 5×4×3=60.

Source / fact used

Verified via web search (summarizing codesandciphers.org.uk and related cryptology references): the standard Army/Luftwaffe Enigma I used 3 rotors selected from a set of 5, giving 60 possible rotor orderings — matches the puzzle's numbers exactly.

What Elsie Left You
