Mission 01 · Easy

The Telegram From 1888

Answer: van Gendt
How to get there

Search "Concertgebouw Amsterdam architect." The building was designed by Adolf Leonard van Gendt, who was inspired by the Gewandhaus concert hall in Leipzig, built two years earlier. Construction ran 1883-1886; the grand opening was 11 April 1888.

Why this is the only answer

Only one architect is credited with the building — every reputable source (the Concertgebouw's own history page, Wikipedia) names Van Gendt specifically.

Source / fact used

Verified via web search against the Concertgebouw's official history page (concertgebouw.nl/en/our-history/history) and Wikipedia ("Concertgebouw, Amsterdam").

The Apprentice's Word List

How to get there

Why this is the only answer

Exactly one word in the list takes "het" instead of "de"; the other four are consistently "de" words.

Mission 03 · Medium

The Grote Zaal's Missing Floor Plan

Answer: 360 (square meters)
How to get there

Split the L-shape into two rectangles: a left piece 18 m wide × 16 m tall (= 288 m²), and a right piece 6 m wide × 12 m tall (= 72 m²). Add them: 288 + 72 = 360 m². (Cross-check: outer rectangle 24 m × 16 m = 384 m², minus the 6 m × 4 m notch = 24 m², gives 384 − 24 = 360 m² — same answer either way.)

Why this is the only answer

Every dimension needed is labeled on the diagram, and the two decomposition methods above agree, confirming there's no ambiguity in the shape.

Source / fact used

Mission 06 · Hard

The Strip Beneath the Podium

Answer: Museumplein
How to get there

Decoding letter by letter using a standard Morse code chart: -- = M, ..- = U, ... = S, . = E, ..- = U, -- = M, .--. = P, .-.. = L, . = E, .. = I, -. = N → M-U-S-E-U-M-P-L-E-I-N → "Museumplein."

Why this is the only answer

Morse code is a fixed, unambiguous 1-to-1 letter mapping (International Morse Code / ITU standard) — there is exactly one valid decoding of this strip.

Source / fact used

Standard International Morse Code alphabet, re-verified letter by letter via web search. Museumplein confirmed as the Concertgebouw's home square via the Concertgebouw's own "Getting there" page and Wikipedia's "Museumplein" article (address: Concertgebouwplein 10, on Museumplein, Amsterdam).

Mission 07 · Hard

Two Stagehands, One Fib

Answer: Femke
How to get there

Suppose Femke tells the truth. Then her statement "Joost and I are both fibbing" would have to be true — but that would mean Femke is fibbing, which contradicts "Femke tells the truth." Contradiction — so Femke must be the one fibbing.
Check: if Femke is fibbing, her statement is false, so it is NOT true that both are fibbing. Since Femke IS fibbing, that only works if Joost is NOT fibbing (i.e. Joost tells the truth). No contradiction — this is the consistent solution.

Why this is the only answer

This is a classic self-referential knights-and-knaves setup: assuming Femke is truthful leads to a direct contradiction, so only one assignment (Femke fibs, Joost is truthful) is logically consistent. Solvable purely by reasoning, no lookup needed.

Source / fact used

Original knights-and-knaves puzzle (Intermediate tier), solved independently to confirm exactly one forced solution.

Mission 08 · Hard (Multi-Stage)

Three Halls, One Coded Note

Stage 1 answer: USA

The three most acoustically praised concert halls built before 1901 are the Grosser Musikvereinssaal (Vienna, Austria), Symphony Hall (Boston, USA), and the Concertgebouw (Amsterdam, Netherlands). The Concertgebouw is already named in the mission; the remaining North American one is in the USA.

Stage 2 (final) answer: podium drawer
How to get there

"USA" has 3 letters, so the shift number is 3. The coded note "SRGLXP GUDZHU" was created by shifting each letter of the real message FORWARD by 3 (a Caesar cipher). Shifting each letter BACKWARD by 3 recovers it: S→P, R→O, G→D, L→I, X→U, P→M ("PODIUM"), and G→D, U→R, D→A, Z→W, H→E, U→R ("DRAWER") → "PODIUM DRAWER."

Why this is the only answer

Stage 2 genuinely depends on Stage 1: without knowing the shift is 3 (from "USA"), the cipher can't be reversed. A Caesar shift is a fixed, reversible 1-to-1 substitution, so there is exactly one correct decoding once the shift is known.

Source / fact used

Acoustics ranking verified via web search (multiple sources agree on these three specific halls, all pre-1901, all "shoebox" shaped). Caesar cipher re-verified by re-encoding "PODIUM DRAWER" with a +3 shift and confirming it reproduces "SRGLXP GUDZHU" exactly.

Big "Aha!" Moment

The Drawer's Two-Digit Code

Answer: 80
How to get there

Recall the number planted in Mission 02: 46 (composer surnames carved into the Grote Zaal's walls). Double it: 46 × 2 = 92. Subtract 12: 92 − 12 = 80.

Why this is the only answer

The riddle gives an exact, unambiguous two-step calculation (double, then subtract 12) applied to a single fixed number planted six missions earlier. If your child forgot to jot down "46" in Mission 02, they can scroll back up to that mission's Agent's Notebook aside — that's expected and fine.

Source / fact used

The "46 composer surnames" fact is real, verified via web search (multiple sources on the Concertgebouw's interior decoration note that surnames of 46 composers, from Bach and Mozart to Mahler and Bartók, are displayed on the Grote Zaal's balcony ledges and walls).
